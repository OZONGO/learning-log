## 一、星号的两副面孔（课堂记录）

- **def 处＝打包（吸）**：`*args` 吸走多余**位置**参数成 **tuple**；`**kwargs` 吸走多余**关键字**参数成 **dict**。`args`/`kwargs` 只是惯例名，语法在星号。
- **调用处＝解包（拆）**：`f(*容器)` 把容器拆成散装位置值；`f(**字典)` 拆成散装 `名=值`（等价于逐条手写 `名=值` 传参）。
- 口诀（本人收工原话）："**def 处是打包，调用处解包**"。
- 同线会师：`show(*nums, **info)`——调用处先拆成散装参数流，def 处磁铁再吸回容器；"散装参数流"是 Python 里参数唯一真实的形态。

## 二、实验记录与口答（誊自本人）

- **实验①**（`args_lab.py` 前半）：四行调用预测注释与实际输出全部逐字命中，含 `(9,)` 单元素元组尾逗号、`show()`"两个都是空容器（不是 None）"。
- **实验②**（`args_lab.py` 后半）：两枚运行时物证——
  - `total(*[1, 2])` → `TypeError: total() missing 1 required positional argument: 'c'`
  - `profile(**{"name": "王五"})` → `TypeError: profile() missing 1 required positional argument: 'age'`
- **松紧口答（本人原话）**："subject_avg(*scores) 分数不由函数决定，由调用的数据决定；profile(name, age, **rest) 函数需要某些东西，并且 **rest 可以接收以后可能加的。"
- **报错术语口答（本人原话，全对）**：positional 跟着 **def 行的身份表**走，与调用时用 `*` 还是 `**` 无关；参数没被成功赋值就按定义表身份报缺。
- **AI 补全术语地图**：普通参数（位置/名字两渠道都可喂）缺→报 `positional`；`*` 之后的参数只能喂名字、缺→报 `keyword-only`。`*args` 那颗星同时是**分界线**——顺序规矩（普通→\*args→\*\*kwargs）的形状由此而来。
- **课中事故留档（教练的错）**：教案打字多出一个 `"` → `SyntaxError: unterminated string literal`，且把 `'''...'''` 误当注释（注释必须 `#`）。教训：**SyntaxError＝整个文件一行不跑**，此时贴回的任何运行时输出都可能是修语法前的旧账——先修语法、再跑实验、再对账。

## 三、我给自己提的醒（誊自收工口答）

- `args` 是 **tuple 不是 list**，体内 `args.append(99)` 直接 `AttributeError`——"手里是什么类型"的元问题在函数体内照样适用。
- **拆包是倒货，不是补货**：星号不负责凑数，多了少了都由函数按收货单点货报错。

## 四、一句话总结（誊自本人收工口答）

本人原话："增加或修改科目后，需要维护多处。"——AI 补根因：这是**症状**；病根五个字＝**焊进变量名**（科目本是数据、躺在 dict 键里，却被焊进代码标识符）。——2026-09-10 订正：原文误记"四个字"，本人复习时当场指出实为五个字。本课的药：个数交给磁铁、逻辑收进函数——加科目＝只加数据，代码不动。
