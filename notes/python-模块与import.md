## 一、概念（誊自本人口答）

- 模块＝一个 .py 文件；import＝Python 把那个文件**从头到尾执行一遍**——执行的只有**顶层（无缩进）语句**；模块里的 `def` 只"造工具挂名字"，函数体不跑。（收工费曼 A 点："将重复使用的功能高内聚"——复用是模块的第一存在理由。）
- 两种姿势的选型（本人原话）："一个是导入了整个模块，一个是仅 rect_area 函数；要使用模块中多个功能时或模块名能提供重要上下文时导入整个模块，只使用某个功能就导入某个方法。"——费曼 C 点补机制：`模块名.名字` 是**命名空间**，防冲突、保来源追溯（与"避免 global＝写入点要看得见"同族）。
- 守卫（本人原话）："直接运行模块文件时执行，导入其他文件时不执行；将 `__name__` 变量设置为该模块的名称；让同一个 .py 文件既能作为被调用的工具库（导入时不运行测试代码），又能作为独立程序（直接运行时执行核心逻辑）。"
- 遮蔽（本人原话）："会拿到自建的，因为 Python 优先找当前目录。"
- **措辞更正（记自查项；①于 2026-09-11 订正）**：①守卫的 `if` 那**一行本身是顶层语句**，import 时照样执行（求值条件）；不执行的是它**缩进的函数体**——准词"守卫这一句跑了，分支没进"。原记"守卫那两行也执行"不精确（学习者 2026-09-11 当场指出；教练同日还误把此点当成学习者遗漏，实为教练错案）；②点号后面接的是**函数**，挂在类里的才叫**方法**——本课内三次口头说成"方法名"（挑刺两次后收工仍滑），面试措辞要改。

## 二、课中实验记录

- `python area_mod.py` → "模块 area_mod 被加载了"＋"我是被直接运行的"；`python use_area.py` → "模块 area_mod 被加载了"＋`12.56636`＋`12`，**守卫那句没出现**。预测与实际一致。

## 四、一句话总结（本人收工原话）

模块导入时只执行顶层语句。

—— AI 补引申（标注为补笔）：这条是今天所有现象的共同根——证人 print 会出现、def 不跑函数体、被 import 时守卫分支不进，三件事一个因。
