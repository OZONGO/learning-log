## 一、概念卡（复习时先看这里）

### bool 与比较运算
- bool 只有两个值：`True` / `False`（首字母必须大写，小写报 `NameError`）
- 比较运算（`==` `!=` `<` `>` `<=` `>=`）的结果就是 bool——"问问题"的答案
- `=` 贴标签（赋值）；`==` 问"相等吗"。判断里写 `=` 是语法错误（Python 故意保护）

### 算术运算符
| 符号 | 含义 | 例子 |
|---|---|---|
| `/` | **真除法**（结果总是带小数） | `7 / 2` → 3.5 |
| `//` | 整除（丢掉小数） | `7 // 2` → 3 |
| `%` | 取余 | `7 % 2` → 1 |
| `**` | 幂 | `2 ** 3` → 8 |

- 恒等式：**被除数 = 商 × 除数 + 余数**（`9 = 4×2 + 1`）。`//` 与 `%` 常成对出现，用来做"拆解"

### 逻辑运算符
- `and`：两边都 True 才 True；`or`：只有两边都 False 才 False（有一个就行）；`not`：取反
- 助记：用"反面"描述 or 比背口诀牢——"全 False 才 False"

### if / elif / else
- 语法三件套：**冒号 + 缩进（4 空格）+ 从上往下命中第一个 True 就整条链结束**
- `elif` 链保证"最多走一个分支"（互斥是结构保证的）
- **拆成独立 `if` 就各走各的**：条件都满足会都执行；且 `else` 只归**最近的 if** 管
  （本课实证：`guess=50` 时 elif 版只输出"大了"；拆成独立 if 后输出"大了"+"恭喜猜对！"）

### while / break / continue
- `while 条件:` 为 True 就执行缩进块，执行完**回来再判断**——与 if 的唯一区别是会反复
- **死循环**：循环里忘了更新条件相关变量 → 无限循环，`Ctrl + C` 急救
- `break`：立刻跳出整个循环；`continue`：跳过本次剩余代码，回到条件判断进下一轮；两者都必须在循环**内部**
- 常用模式 `while True:` + 中途 `break`：停的条件在循环体深处时（如猜中），比写条件进 while 更灵活

### for + range
- `for i in range(start, stop)` 逐个取数，**左闭右开：不含 stop**（`range(1, 6)` = 1~5）
- 为什么开区间：长度永远 = `stop - start`，不用 +1
- **选型**：次数明确/遍历已知的东西 → `for`；次数未知、靠条件停 → `while`（猜数字 vs 打印 1~100）

## 二、易错点清单（W1 写三个练习前必看）

1. `=` vs `==` 混用（判断里用 `=` → 语法错误）
2. `int("3.14")` 崩（`ValueError`）——`int()` 只吃整数字符串；**小数先 `float("3.14")`**
3. `elif` 被拆成 `if` → else 归属错乱（本课最深的 bug，见概念卡）
4. `range(1, 10)` 没有 10（不含 stop）
5. `while` 条件写反 → 循环一次都不执行（本课实证：`while guess == secret` 初始直接跳循环，没猜就"恭喜"）
6. 变量更新写在 `continue` 之后 → 永远被跳过 → 死循环
7. 忘冒号 / 缩进乱 → `SyntaxError`（VS Code Tab 自动 4 空格）
