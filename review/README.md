# review/ 艾宾浩斯间隔复习系统

> 起草：AI ｜ 内容确认：OZONGO
> 叠加在现有「待复述问题清单＋弱点清单」之上的轻量间隔重复层，不替代任何现有流程。
> 依据：遗忘先快后慢（1 天后仅剩约 34%）；主动回忆远胜重读；扩展间隔 1/2/4/7/15/30/60 天。
> 每天约 15 分钟，嵌入学习会话开场（先清到期复习，再开新课）。

## 文件职责

| 文件 | 角色 | 维护方 |
|---|---|---|
| queue.md | 中央复习队列——档位/到期/状态的**唯一活跃真相源** | AI（教练技能读写） |
| log.md | 复习日志（追加式，永不改历史行） | AI |
| weaknesses.md | 弱点登记表 WK-xxx（跨笔记集中，含已结案留档） | AI |
| README.md | 本说明 | AI |

## 间隔档位（固定扩展式）

| 档位 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 毕业 |
|---|---|---|---|---|---|---|---|---|
| 天数 | 1 | 2 | 4 | 7 | 15 | 30 | 60 | — |

## 三档评分与转移规则（每次复习后更新 queue.md）

- **记得**（脱稿答清，达笔记自带通关标准）→ 档位 +1（档位 6 通过→毕业）；下次到期 = 今天 + 新档位天数
- **模糊**（部分答上/需提示）→ 档位 -1（最低 0）；下次到期 = 今天 + 新档位天数
- **忘了**（核心内容答不出）→ 档位归 0；下次到期 = 明天；弱点卡 → weaknesses.md 状态改 recurred；笔记卡 → 答不上的题登记为新弱点（或关联已有 WK）
- 复习次数：终身累计只增不减。毕业卡移入 queue.md 底部「已毕业」区留档（阶段面试可抽）

## 每日流程（会话开场，约 15 分钟）

1. 教练读 queue.md，抽出「下次到期 ≤ 今天」的卡（逾期一并算到期）。
2. 学习者**合上代码与笔记脱稿口答**：笔记卡＝答该篇第零节清单（按其自带通关标准）；
   弱点卡＝用自己的话讲清该弱点＋举一个自己代码里的真实例子。
3. 教练按三档评分，更新 queue.md（档位/上次复习/下次到期/次数/状态），涉及弱点时同步
   weaknesses.md，并向 log.md 表头下插入一行。
4. 清完到期卡再开新课。收尾 git 由用户本人执行：
   `git add -A && git commit -m "review: 清 X 张到期卡（记得Y/模糊Z/忘了W）" && git push`
5. 与看板 0.9 定例的关系：本流程是 0.9 的**升级**——从「每场全量自测最新一篇」升级为
   「按到期清单自测」。最新笔记几乎每天在到期名单里（自然覆盖），旧笔记按档位到期才测。

## 入队规则

- **新笔记**：成文（含零节清单）当天，AI 在文件头加 frontmatter（id 顺延、created=当天、
  weakness_ids=[]），queue.md 表尾追加一行：档位 0、下次到期 = 明天。
- **新弱点**：会话/练习/面试中发现 → weaknesses.md 追加行（下一 WK 号、严重度 低/中/高、
  状态 open），queue.md 追加弱点卡（档位 0、次日到期）。
- **弱点结案**：对应卡连续两次「记得」且无复现 → 状态改 resolved、填结案日、卡片移出活跃队列。
- **面试遗忘点**：interviews/ 记录中「连续两次答错的同类题」或新盲区 → 生成新弱点卡入队
  （把 06 模板"标红强制进下周计划"落为可排程的卡）。

## 周复盘联动（周日，填 06 第六节）

- 执行率 = 本周已清到期卡 / 本周到期卡；三档分布；弱点新增/结案/复现；
  到期未清的卡自动滚入下周（队列不改，复盘只记趋势）。

## 升级接口（W3 学完函数后自写 review_scheduler.py 的数据约定）

- queue.md / weaknesses.md 为严格可解析 Markdown 表格：每行 `|` 起止、列数固定、
  日期一律 `YYYY-MM-DD`、无合并单元格。
- 未来脚本：解析表 → 筛「下次到期 ≤ 今天」→ 输出清单 → 接收三档评分 → 按转移规则回写。
- ease 字段当前固定 2.5，为 SM-2 式自适应升级预留；升级只加脚本，不动本目录结构。
